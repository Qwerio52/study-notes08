# study-notes08

#### \# 第9章 面向对象编程 学习心得

> 学习内容：类与对象、构造方法、属性与方法、类的继承、运算符重载、模块和程序包封装



\## 知识点梳理

本章从“万物皆对象”切入，讲解Python面向对象程序设计，核心四大要点：

1\. \*\*类和对象\*\*：类是抽象模板，对象是类的实例；类包含描述特征的\*\*属性\*\*和描述行为的\*\*方法\*\*。

2\. \*\*构造方法 `\_\_init\_\_()`\*\*：实例化对象时自动调用，用于初始化对象属性。

3\. \*\*类的继承\*\*：子类可以复用父类的属性和方法，支持代码复用、扩展原有功能。

4\. \*\*运算符重载\*\*：重写特殊方法，让自定义类的对象支持 `+`、`-` 等运算符操作。

5\. \*\*模块与程序包\*\*：把代码拆分封装成模块、包，方便项目管理、代码复用。



\## 学习心得

在学习本章之前，我写代码大多采用\*\*面向过程\*\*的思路：变量保存数据，函数单独处理数据，数据和操作是相互分离的。面向对象编程改变了我的思维方式，它将事物的属性和行为打包封装为一个整体，也就是类。



封装是面向对象第一个给我留下深刻印象的特性。以图书借阅系统为例，图书的书名、编号、借阅状态作为属性，借阅、归还作为方法，全部封装在图书类内部。外部只需要创建图书对象、调用方法，不需要关心内部如何修改借阅状态，降低了代码逻辑的复杂度。



继承机制让我感受到代码复用的优势。子类可以直接继承父类已有的属性和方法，不需要重复编写相同代码，还能新增自己独有的功能，符合代码设计“少写重复代码”的原则。



运算符重载是比较有趣的部分。通过重写 `\_\_add\_\_` 这类特殊方法，我们可以让自己定义的类支持加减运算，就像内置数字类型一样自然，让自定义对象使用起来更灵活。



最后学习了模块和程序包封装。随着项目代码越来越多，全部写在一个py文件里会很难维护。将功能拆分到不同模块、组织成包，是大型项目的组织方式，也和前面第八章学习的Python计算生态、第三方库思想呼应。



\##难点总结

1\. 容易混淆\*\*类\*\*和\*\*实例对象\*\*：类只是模板，只有实例化之后才会生成独立的对象，每个对象拥有自己的属性；

2\. 对self参数理解不熟练：self代表实例本身，在类内部访问属性、调用方法必须依靠self；

3\. 继承时父类构造方法的调用顺序、特殊方法名称容易记混。



\##学习收获

面向对象不是单纯新增语法，而是一套新的建模思维。遇到问题时，不再只想着“一步步做什么”，而是思考系统里有哪些事物、事物有什么特征、能做什么动作。这种思维方式，为后续学习大型项目开发、框架使用打下了基础。
